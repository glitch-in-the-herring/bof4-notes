The player's combatant data starts at `0x801c79b8` in the RAM and is 420 bytes long for each combatant. 

| Position | Description              | Value(s)                       | Note                                                                                                                                                                       |
| -------- | ------------------------ | ------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1        | Order                    | 8-bit signed integer           | The order of the party member in the battle party                                                                                                                          |
| 156-163  | Name                     | ASCII null-terminated string   |                                                                                                                                                                            |
| 164      | Character ID             | 8-bit signed integer           | The unique ID that defines the character, see [[Party Ordering]]                                                                                                           |
| 166      | Level                    | 16-bit unsigned integer        |                                                                                                                                                                            |
| 168-171  | EXP                      | 32-bit signed integer          |                                                                                                                                                                            |
| 176-179  | Current HP               | 32-bit signed integer          |                                                                                                                                                                            |
| 180-183  | Current AP               | 32-bit signed integer          |                                                                                                                                                                            |
| 186-201  | Magic                    | 8-bit unsigned integers        |                                                                                                                                                                            |
| 202-211  | Skills                   | 8-bit unsigned integers        |                                                                                                                                                                            |
| 212-215  | Current max HP           | 32-bit signed integer          | Current max HP drops when the party member is knocked out mid-battle and is not revived during the battle. It is restored back to the true max HP after resting in an inn. |
| 216-219  | Current max AP           | 32-bit signed integer          |                                                                                                                                                                            |
| 220-221  | Effective CP             | 16-bit unsigned integer        | This is the combatant's CP after all equipment modifiers.                                                                                                                  |
| 222-223  | Effective PWR            | 16-bit unsigned integer        | This is the combatant's PWR after all equipment modifiers and buffs/debuffs.                                                                                               |
| 224-225  | Effective DEF            | 16-bit unsigned integer        | This is the combatant's DEF after all equipment modifiers and buffs/debuffs.                                                                                               |
| 226-227  | Effective AGL            | 16-bit unsigned integer        | This is the combatant's AGL after all equipment modifiers and buffs/debuffs.                                                                                               |
| 228-229  | Effective WIS            | 16-bit unsigned integer        | This is the combatant's WIS after all equipment modifiers and buffs/debuffs.                                                                                               |
| 230-241  | Effective resistances    | 8-bit unsigned integers        | This is the combatant's resistances after all equipment modifiers and buffs/debuffs.<br>See [[Resistance]] for the order of resistances.                                   |

| 243      | Effective counter rate   | 8-bit unsigned integer         | This is the combatant's counter rate after all equipment modifiers and buffs/debuffs.                                                                                      |

| 252-255  | True max AP              | 32-bit signed integer          |                                                                                                                                                                            |
| 256-257  | True CP                  | 16-bit unsigned integer        | This is the combatant's CP without equipment modifiers. Levelling up directly increases this stat.                                                                         |
| 258-259  | Base PWR                 | 16-bit unsigned integer        | This is the combatant's PWR without any equipment modifiers and buffs/debuffs. Levelling up or using permanent stat increasing items directly increases this stat.         |
| 260-261  | Base DEF                 | 16-bit unsigned integer        | This is the combatant's DEF without any equipment modifiers and buffs/debuffs. Levelling up or using permanent stat increasing items directly increases this stat.         |
| 262-263  | Base AGL                 | 16-bit unsigned integer        | This is the combatant's AGL without any equipment modifiers and buffs/debuffs. Levelling up or using permanent stat increasing items directly increases this stat.         |
| 264-265  | Base WIS                 | 16-bit unsigned integer        | This is the combatant's WIS without any equipment modifiers and buffs/debuffs. Levelling up or using permanent stat increasing items directly increases this stat.         |

| 278      | Base learning rate       | 8-bit unsigned integer         | This is the combatant's learning rate without any equipment modifiers and buffs/debuffs.<br>See [[Learning]] for information about how this is used                        |
| 279      | Base counter rate        | 8-bit unsigned integer         | This is the combatant's counter rate without any equipment modifiers and buffs/debuffs.                                                                                    |
