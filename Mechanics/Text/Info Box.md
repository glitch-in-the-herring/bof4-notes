## Rendering
The rendering of info boxes involves two steps:
* Rendering the box
* Rendering the text
These are independent of each other.
### Box
The function that renders the box can be found at:
* `0x801510e8` in the RAM
* `SLUS_013.24: 000590e8` in the game's files
The function takes four arguments as input:

| Argument | Description         |
| -------- | ------------------- |
| `$a0`    | Box x position      |
| `$a1`    | Box y position      |
| `$a2`    | Box width           |
| `$a3`    | Box height and mode |

The height and mode byte determines how tall the box is and whether or not the small "Info" text at the top left appears. 
Height is controlled by the first digit of the byte:

| ID     | Type        | Height |
| ------ | ----------- | ------ |
| `0x0_` | Single-line | 20     |
| `0x1_` | Double-line | 34     |
The height values can be found at:
* `0x801747c8` in the RAM
* `SLUS_013.24: 0007c7c8` in the game's files
The appearance of the "Info" text is controlled by the second byte

| ID     | Type        |
| ------ | ----------- |
| `0x_0` | No "Info"   |
| `0x_1` | Show "Info" |

Then when a message is shown during battle, the height loaded depending on the type of message. For enemy messages, the double-line height is used:
```
801ccef8 li     $v1, 0x0010 ; load height
801ccefc sb     $v1, -0x21e8(a0) ; store height
```
This can be found at `BIN/BATTLE/BTLMOVE.EMI: 00004ef8`
For other system messages, it is assumed that the previous line height is always reset to the single-line height before displaying it, as it does not store its own line height:
```
801d00a8 sb     $r0, -0x21e8(v0) ; reset line height to single-line
```
This can be found at `BIN/BATTLE/BTLMOVE.EMI: 000080a8`

#### Post-Battle
Even though the dimensions of the post-battle top info box is identical to the [[#Battle Messages]] info box, it uses a completely different code.
```
801ce8b8 li     $v0, 0x0010 ; load box x position
801ce8bc sh     $v0, 0x0008(a0) ; store box x position
801ce8c0 lbu    $v0, 0x0003(a0)
801ce8c4 li     $v1, 0x0014 ; load box y position
801ce8c8 sh     $v1, 0x000a(a0) ; store box y position
```
This can be found at `BIN/BATTLE/BTLEND.EMI: 000288b8`
Then for the text's position and line height:
```
801ce874 24070001: li     $a3(801cc8d0), 0x0001
...
801ce958 lhu    $a0, 0x0008(v1) ; load box x position
801ce95c lhu    $a1, 0x000a(v1) ; load box y position
801ce960 li     $a3, 0x00ff
801ce964 sw     $v0, 0x0010(sp)
801ce968 addiu  $a0, 0x0006 ; add x padding to the box x position, this is the text x position
801ce96c sll    $a0, 0x10
801ce970 addiu  $a1, 0x0005 ; add y padding to the box y position, this is the text y position
801ce974 sll    $a1, 0x10

```
This can be found at `BIN/BATTLE/BTLEND.EMI: 00028874`
