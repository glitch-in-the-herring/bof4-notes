Backlash causes its caster to counter an offensive, purely-elemental spell by repeating it, targeting the combatant that attacked Backlash's caster. 
When cast it sets an unknown flag:
```
801de824 lhu    $v0, 0x0002(v1) ; load current flag
801de828 nop    
801de82c ori    $v0, 0x0800 ; set the backlash byte
801de830 j      0x801de910
801de834 sh     $v0, 0x0002(v1) ; store new flag
```
This code can be found at `BIN/BATTLE/BTLMOVE.EMI: 00016824`
Then, after another combatant casts a spell, it checks if the spell can be repeated:

```
801d1fdc lhu    $a0, 0x0002(a1) ; load spell ID
801d1fe0 addiu  $v1, -0x5230
801d1fe4 sll    $v0, $a0, 0x01
801d1fe8 addu   $v0, $a0
801d1fec sll    $v0, 0x02
801d1ff0 addu   $v1, $v0, $v1
801d1ff4 lhu    $v0, 0x0008(v1) ; load spell icon
801d1ff8 nop    
801d1ffc andi   $v0, 0x000f
801d2000 beqz   $v0, 0x801d2184
801d2004 li     $v0, 0x00ff
; if the first digit of the icon is not zero (i.e. it has at least one of Fire/Wind/Water/Earth as its element)
801d2008 lhu    $v0, 0x0008(v1) ; load spell icon
801d200c nop    
801d2010 andi   $v0, 0xfff0
801d2014 bnez   $v0, 0x801d2184
801d2018 li     $v0, 0x00ff
; if the remaining three digits are zero (i.e. the spell is purely elemental)
801d201c lbu    $v0, 0x0006(v1) ; load unknown byte
801d2020 nop
...
801d216c lhu    $v0, 0x0002(v0) ; load backlash flag
801d2170 nop    
801d2174 andi   $v0, 0x0800
801d2178 beqz   $v0, 0x801d2184
; if the backlash flag is active, repeat spell
801d217c li     $v0, 0x00ff
```
